# TheFloor.TrackerSupreme

TheFloor.TrackerSupreme is a planned web application for tracking The Floor. The planned stack is ASP.NET Core on .NET 10, SignalR, EF Core with SQLite, and a React, TypeScript, Vite, and Tailwind CSS frontend. Playwright will cover browser workflows.

This repository currently contains environment setup and a documentation check. Application design and implementation are reserved for a later session.

See [Environment and verification](docs/environment.md) for tooling, workflow, and setup results.
